# 🛡 WebShield Scanner

## Python Based Website Vulnerability Scanner


## 📌 Project Overview

WebShield Scanner is an automated website security assessment tool developed using Python and Streamlit.

The system performs vulnerability analysis on websites by scanning security configurations, detecting possible vulnerabilities, analyzing risk levels, and generating security reports.


---

# 🚀 Features

## 🔍 Information Gathering

- Website Information Detection
- Technology Stack Detection
- DNS Information Analysis
- Subdomain Enumeration


## 🛡 Security Testing

- Security Header Analysis
- SSL/TLS Certificate Scanning
- Cookie Security Analysis
- HTTP Methods Testing


## 🔥 Vulnerability Detection

- Cross Site Scripting (XSS) Detection
- SQL Injection Detection
- Cross-Origin Resource Sharing (CORS) Testing
- Server Side Request Forgery (SSRF) Testing
- Open Redirect Detection
- Directory Listing Detection
- Information Disclosure Detection


## ⚠ Risk Analysis

- Vulnerability Severity Classification
- CVSS Score Calculation
- OWASP Category Mapping
- CVE Reference Mapping


## 📊 Management Features

- User Authentication
- Admin Dashboard
- Scan History
- Database Storage
- CSV Export
- JSON Export
- Professional PDF Report Generation
